# Security Policy

Bobo Guard is designed as a local-first developer security tool.

## Reporting vulnerabilities

Please open a private GitHub security advisory or contact the maintainer through the profile links on GitHub.

Do not include real API keys, tokens, private keys, cookies, or production logs in public issues.

## Data handling

- Project files are scanned locally.
- Findings are redacted before they are displayed.
- GitHub audits use repository metadata through the local Git credential.
- File contents are not uploaded by the application.

## Scope

Current checks are best-effort heuristics. Treat findings as a review queue, not as a complete security guarantee.
